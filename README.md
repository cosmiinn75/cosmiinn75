## Building TutorFrame

**TutorFrame** is a tutoring management platform I'm developing as a real product for independent tutors, not just a portfolio project. It's currently in development and being prepared for initial user testing.

- **Tutoring workflows:** students, groups, session history, attendance, payments, and learning materials.
- **Scheduling:** recurring schedules, automatic session generation, and session lifecycle management.
- **Product experience:** notifications, secure sharing of session materials, and responsive Flutter interfaces for phones and tablets.
- **Engineering:** REST APIs, authentication, PostgreSQL data modeling, database migrations, and automated tests.

**Stack:** `Java` `Spring Boot` `Spring Security` `Spring Data JPA` `PostgreSQL` `Flutter` `Dart` `Docker`

*Proprietary project — source code is private while I prepare the product for release.*
